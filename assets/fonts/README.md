# Satoshi webfont

`Satoshi-Variable.woff2` is the unmodified normal variable webfont from the official [Fontshare Satoshi family](https://www.fontshare.com/fonts/satoshi), designed by Deni Anggara and distributed by Indian Type Foundry. It supports weights 300–900.

Downloaded on 8 October 2026 from Fontshare's official family package at `https://api.fontshare.com/v2/fonts/download/satoshi`. The accompanying `FFL.txt` contains the complete ITF Free Font License supplied with that package (version 2.0, 17 August 2026).

The portfolio self-hosts this font for its own text rendering. Keep the font unmodified and preserve the supplied licence and notices.
